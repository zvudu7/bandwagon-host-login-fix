## 为什么会出现 host login 提示错误？

搬瓦工（BandwagonHost）的登录页面开启了 Cloudflare 防护，包括著名的"五秒盾"（DDoS protection by Cloudflare）。

原理其实很简单：每次登录请求发出去，Cloudflare 会先做一次检测，等待大约五秒。**问题在于，这五秒的等待有时候和登录表单的提交时序产生冲突**——你的账号密码已经提交了，但 Cloudflare 的验证还没完成，结果搬瓦工后台收到了一个"不完整"的请求，直接返回登录失败。

这不是你的账号出问题了，也不是密码错了，就是时序撞上了。

## 搬瓦工 host login 提示失败的常见原因

### 原因一：Cloudflare 五秒盾时序冲突

最常见的情况。表现为：明明账号密码都是对的，点击登录之后页面直接提示 "Login Details Incorrect"，没有任何其他错误信息。

**解决方法：再登录一两次。** 这个错误绝大多数情况只会出现一次，第二次、第三次重新提交基本上就能成功进入。不要一看到报错就开始改密码——先试试多点几次。

### 原因二：官网域名在国内被屏蔽，根本打不开

搬瓦工主域名 `bandwagonhost.com` 在中国大陆境内无法直接访问。如果你的页面根本加载不出来，连登录界面都显示不了，那问题出在网络访问层，和账号密码无关。

**解决方法：使用搬瓦工官方镜像域名。** 搬瓦工官方提供了多个镜像站，功能和数据完全一致，在国内可以正常访问：

- `bwh81.net`（目前最常用的备用入口）
- `bwh1.net`
- `bwh8.net`
- `bwh88.net`

这些都是搬瓦工官方提供的镜像域名，账号体系完全互通，用哪个登录效果一样。

👉 [点击这里直接进入搬瓦工（备用入口可访问）](https://bwh81.net/aff.php?aff=77528)

### 原因三：浏览器缓存了旧的错误页面

如果之前访问过某个镜像站或者主站，浏览器缓存了一个错误的重定向记录，下次打开就会直接跳到一个失效页面，怎么刷新都不管用。

**解决方法：清除浏览器缓存后重新打开。** 在 Chrome 里是 `Ctrl+Shift+Delete`，选择清除缓存和 Cookie，然后重新访问登录页。

### 原因四：账号确实忘了或者填错了

注册搬瓦工的时候，很多人用的邮箱地址可能已经很久没用了，或者当初手滑打错了。这种情况下用"找回密码"功能也会提示"账户不存在"，因为系统里压根没有这个邮箱记录。

**解决方法：** 如果你有购买记录（支付宝账单、邮件通知等），可以发邮件到 `support@bandwagonhost.com`，说明情况并附上购买凭证，客服一般会在 24 小时内回复帮你找回账户。

### 原因五：搬瓦工官网本身出现故障

历史上搬瓦工也发生过因为硬件故障导致网站整体宕机的情况，比如曾经出现过主板损坏导致官网、KiwiVM 面板、API 全部无法访问，大概持续了两小时。这种情况下你的 VPS 机器本身不受影响，只是后台管理界面打不开。

**解决方法：** 查看搬瓦工官方状态页 `bwhstatus.com`，看看有没有正在进行的维护或者故障公告。如果是官方在维护，等一等就好。

## host login 成功之后：KiwiVM 面板在哪里？

很多新手第一次登录搬瓦工后台（Client Area）之后，找不到管理 VPS 的地方。这里说明一下：

1. 登录 Client Area 之后，点击菜单里的 **"Services"** → **"My Services"**
2. 找到你的 VPS 服务，点击 **"Manage"** 按钮
3. 在服务详情页里，点击 **"KiwiVM Control Panel"** 的链接，就能进入 VPS 管理面板了

KiwiVM 是搬瓦工自有的 VPS 控制面板，在这里可以：
- 开机/关机/重启 VPS
- 重装操作系统（安装 Debian、Ubuntu、CentOS 等）
- 查看 SSH 端口和 root 密码
- 切换机房（迁移数据中心）
- 查看流量使用情况
- 检查 IP 是否被屏蔽（IP 被墙检测）
- 更换 IP 地址
